# 📈 StockSense: Big Data Stock Market Analytics

StockSense is a Big Data analytics project that processes and analyzes historical Indian stock market data using **Apache Spark (PySpark)** and visualizes insights through an interactive **Streamlit** dashboard.

---

## 🚀 Features

- **Big Data Processing with PySpark**:
  - Uses Apache Spark Window functions to compute daily returns, previous close, and historical returns.
  - Computes volatility (standard deviation), average trading volume, and performance metrics across stocks.
- **Indian Market Data**:
  - Covers major Indian stocks (`RELIANCE.NS`, `TCS.NS`, `INFY.NS`, `HDFCBANK.NS`) with 5 years of historical data via Yahoo Finance.
- **Interactive Streamlit Dashboard**:
  - Key Performance Indicators (KPI metrics for volume, returns, and best performer).
  - Interactive multi-stock comparison charts (Closing prices, daily return %, trading volume).
  - Date filtering and stock selector.
  - Performance summary table and CSV data export.

## ⚡ Quick Start Guide

### 1. Clone the Repository
```bash
git clone https://github.com/24dit057/StockSense-BigData.git
cd StockSense-BigData
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```
*(Or install manually: `pip install pyspark pandas yfinance streamlit`)*

### 3. Run the Big Data Analysis (Apache Spark)
```bash
python analyze_stocks.py
```
This downloads 5 years of stock data, starts a local Spark cluster session, computes daily & summary statistics, and saves the results in `analysis_output/`.

### 4. Launch the Dashboard
```bash
streamlit run app.py
```
Open your browser at `http://localhost:8501` to view the interactive dashboard!
